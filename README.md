# RocoNatureCalc

洛克性格计算器，记录战斗伤害和生命变化，判断奇遇精灵的性格增减。适用于 Windows x64。

[下载程序](https://github.com/SOXhahaha/RocoNatureCalc/releases/latest) · [使用说明](使用说明.md)

下载 EXE 后直接运行，先在设置里配好自己的精灵，再选择敌方、填写伤害。程序会在同目录生成“缓存”文件夹，更新时保留它即可。

不知道怎么填，可以把使用说明交给 AI，再附上截图提问。出现冲突先检查双方的攻防、威力 Buff。
